Aktivitas 1: Eksperimen "10" + "20"

Kode Program (lkpd_string_number_sridewi.js)

Aktivitas1.js 
let a = "10";
let b = "20";
console.log(a + b);
// Output Console:

> 1020

Prediksi & Output Program

Hasil: "1020"

Mengapa hasil tersebut terjadi?

Karena operator + pada dua tipe data String berfungsi untuk menggabungkan teks (konkatenasi), bukan menjumlahkan secara matematis.

Apakah a dan b bertipe Number?

Tidak, keduanya bertipe String karena nilainya diapit oleh tanda petik (" ").

Pengujian Langsung:

Prediksi benar! Setelah dijalankan pada konsol browser, hasilnya adalah penggabungan teks yaitu 1020.

Kode Program

Aktivitas2.js 
let nama = "Asep";

Variabel Nilai Prediksi Hasil typeof Kesimpulan
nama "Asep" string string Tipe data Teks
umur 16 number number Tipe data Angka

Temuan Penting: Perbedaan String dan Number

String adalah kumpulan karakter/teks yang wajib diapit tanda petik dan tidak bisa dihitung secara matematis. Sedangkan Number adalah nilai numerik murni tanpa tanda petik yang digunakan untuk perhitungan aritmatika.

Think - Pair - Share

Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung?

Karena fungsi prompt() secara otomatis mengembalikan nilai berjenis String. Jika langsung dihitung tanpa konversi, operasi penambahan (+) akan melakukan penggabungan teks (konkatenasi) dan bukan penjumlahan angka.

Apa perbedaan "10" dengan 10?

"10" adalah String (teks yang diapit petik), sedangkan 10 adalah Number (nilai murni angka).

Apa yang terjadi jika lupa Number()?

Hasil penjumlahan akan menjadi gabungan teks angka (misalkan 10 + 20 menjadi "1020").

Pair (Bandingkan Teman)

Hasil perbandingan dengan teman adalah SAMA, karena aturan sintaks dan konsep tipe data pada JavaScript berlaku secara universal.

Share (Temuan Penting)

Menggunakan fungsi Number() sangat krusial saat mengolah masukan dari prompt() agar aplikasi tidak salah menghitung.
